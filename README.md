# Анализ базы данных Northwind на SQL

**Цель проекта:** продемонстрировать навыки написания аналитических SQL-запросов (JOIN, GROUP BY, агрегации, подзапросы, CTE, CASE, работа с датами) на примере учебной базы данных Northwind.

**Используемая СУБД:** PostgreSQL 14

## Основные аналитические блоки

### 1. Общая динамика продаж
- Выручка за 1997 год
- Количество заказов по кварталам 1997 года

### 2. Товарный анализ
- Топ-5 категорий по выручке
- Количество продуктов по категориям
- Распределение товаров по ценовым сегментам

### 3. Клиентский анализ
- Клиенты без заказов
- Самый активный клиент (по числу заказов)
- Контакты из Испании с числом заказов
- Группировка контактов по должностям (Marketing/Sales/Other)
- Клиенты с более чем 10 заказами (CTE)

### 4. Логистика и доставка
- Количество просроченных заказов в 1997 году
- Лучший перевозчик по числу заказов
- Максимальное время доставки

### 5. Анализ сотрудников
- Сотрудник с максимальным числом заказов (общий и по месяцам)
- Сотрудник, работавший с клиентом Francisco Chang
- Гендерное распределение сотрудников
