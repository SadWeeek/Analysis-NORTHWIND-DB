# Анализ базы данных Northwind

В этом репозитории представлены два аналитических проекта, выполненных на основе открытой базы данных Northwind (интернет-магазин). Проекты демонстрируют владение **Python (pandas, matplotlib)** и **SQL (PostgreSQL)** для решения реальных бизнес-задач.

## Проекты

### 1. Анализ продаж и ассортимента (Python)
- **Цель:** выявить динамику выручки, определить топ-10 товаров и топ-5 категорий.
- **Инструменты:** pandas, matplotlib, Jupyter Notebook.
- **Ключевые результаты:**  
  - Пик продаж — декабрь 1997 года.  
  - Лидер продаж — продукт «Côte de Blaye» (выручка ~262 000).  
  - Самая прибыльная категория — «Beverages».
- **Подробнее:** [Pandas_analysis/README.md](Pandas_analysis/README.md)

### 2. Комплексный SQL-анализ
- **Цель:** ответить на вопросы бизнеса с помощью SQL-запросов: динамика продаж, клиентский анализ, эффективность доставки, загрузка сотрудников.
- **Инструменты:** PostgreSQL, агрегатные функции, оконные функции, CTE.
- **Ключевые результаты:**  
  - Выявлено 12 неактивных клиентов (потенциал для ретаргетинга).  
  - Лучший перевозчик — United Package (>300 заказов).  
  - Количество просроченных доставок в 1997 — 23 (≈8%).
- **Подробнее:** [SQL_analysis/README.md](SQL_analysis/README.md)
