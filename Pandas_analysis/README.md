# Анализ продаж Northwind (Python, pandas, matplotlib)

**Цель:** 

- провести базовый анализ продаж 
- выявить динамику выручки 
- топ-товары и категории.

## Используемые библиотеки
- pandas
- matplotlib

## Результаты
- Общая выручка около 1 266 000 (1265793.0395)
- Пик продаж пришёлся на декабрь 1997 года.
- Топ-10 товаров по выручке: Côte de Blaye, ... (см. график в ноутбуке)
- Топ-5 категорий: Beverages, Dairy Products, ... (см. график в ноутбуке)

## Ключевые выводы

- **Общая выручка** за весь период (1996–1998) составила **~1 266 000** (в условных единицах).
- **Пик продаж** пришёлся на **декабрь 1997 года** – выручка достигла максимума, что может указывать на сезонный рост перед праздниками.
- **Топ-3 продукта по выручке:**
  1. **Côte de Blaye** – выручка ~262 000 (дорогой продукт с высокими продажами).
  2. **Thüringer Rostbratwurst** – выручка ~94 000.
  3. **Raclette Courdavault** – выручка ~63 000.
- **Топ-3 категории по выручке:**
  1. **Beverages** (напитки) – лидер с большим отрывом.
  2. **Dairy Products** (молочные продукты).
  3. **Confections** (кондитерские изделия).
